# MOSS-SoundEffect v2.0 本機驗收

驗收日期：2026-10-30（Asia/Taipei）。Windows、RTX 5060 Ti 16GB、64GB RAM；以正式 Studio 音效 API 和瀏覽器介面測試。

## 已交付功能

- 「音效」工作室：中文／英文描述、1～30 秒、Seed、草稿、生成歷史、取消、試聽、下載 WAV、沿用設定。
- 「加入剪輯音軌」明確選擇新專案或既有專案。匯入獨立音訊副本，保留既有剪輯，提供四條音軌的定位、音量及淡入淡出。
- 共用 GPU 鎖涵蓋等待佇列、卸載確認、生成與子程序回收。Windows 取消會終止該工作自己的整個程序樹，等程序離開後才釋放鎖。
- 本版在本機 NVIDIA GPU 執行；遠端連線會明示尚未支援。文字音效不會自動對齊影片動作。

## 固定來源與執行設定

模型：[OpenMOSS-Team/MOSS-SoundEffect-v2.0](https://huggingface.co/OpenMOSS-Team/MOSS-SoundEffect-v2.0)，revision `e35df4d82fbe87fcd5d14e5d100e349c0c3c076d`，Apache-2.0。

程式：[OpenMOSS/MOSS-TTS](https://github.com/OpenMOSS/MOSS-TTS/tree/934d6826b084c46a0d033402174d5f8ac4ed2519/moss_soundeffect_v2)，revision `934d6826b084c46a0d033402174d5f8ac4ed2519`。來源封裝及模型權重均完成 SHA-256 檢查；模型檔案合計 11,232,493,785 bytes。

獨立 Python 3.12 環境、PyTorch 2.9.0+cu128，官方 100 步、CFG 4、sigma shift 5。Windows 關閉編譯，先在 CPU 載入，再使用官方分階段 CPU 卸載機制；推論期間離線。沿用上游的固定 30 秒 latent 窗口，再裁出要求長度。每項工作完成後退出程序，下一項重新載入模型。

## 速度與顯存

完整工作耗時包含啟動獨立程序、匯入、載入、推論、寫 WAV 與回收，不包含排隊等待。推論耗時包含文字編碼、100 步採樣與音訊解碼。數字為單次測試，會受硬碟、記憶體及其他程式使用影響。

|---|---:|---:|---:|---:|---:|

PyTorch 保留記憶體峰值皆為 8.92 GiB；整卡峰值由 `nvidia-smi` 每 250ms 取樣，包含桌面、其他程式與 CUDA 保留量，不能與單一模型的配置量混為一談。這五項測試均完成，沒有 OOM。短輸出仍使用同一個內部窗口，因此 3 秒音效並不保證比 15 秒快。

## 聲音與剪輯檢查

五份 WAV 都是 48kHz、單聲道 IEEE float，長度符合請求；數值有限、非無聲、超過滿幅的樣本比例為零。瀏覽器原生播放器完整播放 3 秒玻璃音效，背景工作更新後播放位置與完成狀態仍保留。

另外使用 [LAION CLAP](https://huggingface.co/laion/larger_clap_general)（revision `ada0c23a36c4e8582805bb38fec3905903f18b41`）在 CPU 比較聲音與候選描述。五份音效的對應描述均排第一，候選也包含語音、音樂、引擎、狗叫、噪音與無聲。這是相對語意檢查，並非校準的品質分數；沒有進行人耳盲聽或主觀音質評分。

以介面建立音效專案，再把第二份音效加入同一專案的 A2，A1 的原有設定保留。玻璃設在第 1 秒開始、音量 60%、淡出 0.25 秒，腳步在第 0 秒開始。6 秒 MP4 匯出包含 144 幀、1280×720、24fps 與 48kHz AAC；解碼聲音與獨立計算的混音參考相關係數為 **0.99846**，尾段靜音符合預期。

另以介面建立取消測試，在進入 GPU 採樣、介面進度 36% 時取消；Windows wrapper 及其實際 Python 子程序均已退出，工作鎖和顯存回到閒置狀態。既有 480 份設定、工作及專案 JSON 的 SHA-256 均保持不變。

## 回歸與證據

前端完整 1,197 項通過。後端完整 1,458 項中 1,457 項通過，1 項既有 Qwen 原生 CPU 合約另在具備 PyTorch 的環境補驗。涵蓋請求驗證、網路重送去重、取消樹、共享鎖、卸載確認、試聽／下載、獨立音訊副本與剪輯音軌；安裝器另核對不完整檔案及同大小損壞內容，Windows 啟動檔驗證 CRLF。

本機驗收資料位於工作區 `artifacts/sfx-integration-20261030/`：生成結果、五份 WAV、數值／CLAP 報告、顯存取樣、混音 MP4 與測試紀錄。模型、私人設定及驗收媒體不納入 Git。
