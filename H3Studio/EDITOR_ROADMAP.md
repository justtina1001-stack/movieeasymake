# 剪輯室功能範圍與後續順序

2026 年 10 月 17 日已新增獨立 5,000 句字幕容量、素材搜尋與預覽、背景片長與顏色、主機匯出歷史，以及可續編的匯出與可取消上傳。詳見 [本次更新](UX_UPDATE_2026-10-17.md)。

此工具以本機生成作品接續剪輯為主；以下明確區分目前功能與尚未實作項目，不代表已完整替代 CapCut。

素材庫支援「移除」及「已移除素材 → 還原」。這是所有專案共用的素材清單，移除會保存可還原狀態，仍保留時間軸、草稿、復原記錄與工作快照所需的來源；不釋放檔案占用的磁碟空間。再次從「生成作品」匯入同一來源會還原原有素材，沿用識別碼及快取。

字幕操作集中在右側「字幕」工作區，左側只保留入口。「文字校對」包含唯一的文字輸入欄、可展開的時間調整、逐句清單與上一句／下一句；「樣式與動畫」沿用文字圖層與整軌樣式工具；「產生／匯入」包含語音辨識及 SRT 匯入。點選時間軸字幕會自動進入校對；切換字幕軌會同步選取該軌句子。一般文字、影片與圖片仍使用片段設定。所有字幕編輯沿用原有專案、復原與自動儲存流程。

「調色與濾鏡」會建立獨立 F1 調色片段，可選取影片時段、目前位置三秒或整支影片；拖曳本體及兩端可移動、裁切範圍，支援方向鍵逐影格調整、分割、複製、刪除與復原。提供曝光、亮度、對比、飽和度、色溫、色調、高光、陰影及濾鏡強度，內建自然、暖色、冷色、黑白、電影感、鮮明六組起始設定。調色作用於時段內的整個合成畫面，含影片、圖片和文字；不修改來源、音訊或成片長度。最多 20 段、同時 4 段，重疊依建立順序疊加；保存、草稿、匯出與第 12 版完整專案備份皆保留設定。

建議接續順序：

1. **主影片基本調整及進階字幕**：主影片裁切／縮放／旋轉、逐字動畫，預覽與匯出一致。
2. **轉場與時間軸**：在交叉淡化、擦除及入場／退場預設上，增加更多效果與更完整的時間軸吸附。
3. **進階音訊及速度**：波形、錄音、響度／降噪、光流慢動作；需另外測試 CPU／GPU 成本及音畫同步。
4. **關鍵幀與效果**：在文字／圖片位置動畫上，增加影片、縮放／旋轉／透明度動畫、調色與遮罩等，保持復原、預覽與匯出一致。

去背、追蹤、光流等 AI 功能仍需選擇對應模型／運算方式；本機自動字幕另以 Whisper small 辨識，使用 CPU，不依賴 H3 生成模型或外部付費服務。

## CapCut 工作流程進化（2026-10-13）

- **字幕面板**：手動加入字幕；SRT 整份匯入為新字幕軌，按句子定位後可在既有設定欄修改內容、時間及動畫；以 UTF-8 匯出所選字幕軌。支援 UTF-8／UTF-16 BOM 及手動選擇 Big5。檔案格式、時間重疊、至少一影格、影片範圍與剩餘圖層容量均在整次匯入前檢查，錯誤不會留下半份字幕。
- **字幕樣式**：白字描邊、醒目黃字、深色底三種樣式；也可把選取文字的完整外觀套用至同一字幕軌，保留每句內容、時間與動畫。SRT 本身只交換文字及時間，字型與效果保存在剪輯專案。
- **批次動畫與轉場**：選取片段後，可將入場／退場／文字待機效果套用至同軌同類片段；轉場套用至所選影片軌相接的交界。短片段自動縮限時長，轉場重建各交界的片段關聯；空白間隔不強行套用。選取「無」後可整軌清除該類效果。所有批次操作是一個復原步驟。
- **沿用效果引擎**：已存在交叉淡化、左右擦除、閃白、模糊溶接、波浪扭曲、RGB 故障、放射及橫向模糊；文字入場／退場及呼吸／浮動／抖動／閃爍待機。此次改善操作，不增加新的渲染公式或新模型。

目前仍維持專案最多 50 個文字／圖片／影片圖層、同時最多 12 個圖層、最長 10 分鐘的範圍；同一字幕軌不接受重疊句子，可分次匯入為多軌。放射轉場仍使用 CPU 匯出，高解析度運算成本未在本輪解決。

流程參考：[CapCut 轉場操作](https://www.capcut.com/help/transitions-in-capcut)、[字幕編輯](https://www.capcut.com/resource/how-to-add-subtitle-in-capcut)、[動畫字幕](https://www.capcut.com/resource/animated-subtitle)。這是本機剪輯功能，未加入 CapCut 素材、帳戶連線或雲端服務。

## 本機自動語音字幕（2026-10-13）

左側「字幕」→「自動語音字幕」可選擇自動判斷語言或中文／英文／日文／韓文，中文可轉繁體。按「產生語音字幕」會先儲存專案，準備剪輯後實際音軌，再在獨立背景程序以 CPU INT8 辨識。包含主影片裁切、固定／曲線變速、原聲音量與淡化、上層影片原聲及配音／配樂混音；音訊時鐘沿用 MP4 匯出的影格取整規則，不需要先渲染整支影片。

首次使用會自動建立獨立字幕 Python 環境並下載約 486 MB 的 multilingual small 模型；之後重用快取，音訊不會送往雲端辨識。模型儲存在 `H3Studio/data/editor/captions/models/small`，依賴在同目錄下的 `runtime`，不更改 Studio 或 ComfyUI 的 Python 套件。

辨識完成後可下載 SRT，或按「加入為新字幕軌」一次加入並復原。文字與外觀可照原有字幕流程修改。結果屬於辨識當時的聲音時間軸；若之後修改裁切、變速、音量、淡化、影片或音軌位置，會停用加入並提示重新辨識，原 SRT 仍可下載。修改字型、樣式或標題不會使結果失效。重開剪輯頁可回復該瀏覽器保留的工作編號，服務重啟則把未完成工作標為中斷，允許重試。

限制：每次最多 10 分鐘、同時一個語音字幕工作；既有字幕與其他疊層合計仍最多 50 個。超過容量時可先下載完整 SRT，不會只加入部分結果。無聲／靜音及沒有辨識到語音會顯示原因。人名、同音字、口音、背景音樂及多人重疊語音仍需人工校對；這一版沒有說話者分離或逐字高亮。

實測已使用一段約 14 秒的中文語音驗證整個工作，另驗證裁切及 1.1／0.9 倍變速後的時間軸辨識與暫存清理。辨識可完成，但「剪輯室」有同音誤字，應在新增字幕後校對。音訊解碼使用有界的 PyAV 16 kHz 單聲道陣列，避免目前 faster-whisper 檔案解碼與 PyAV 18 API 的相容問題。

程式與 Whisper 權重採 MIT；繁體轉換 OpenCC 採 Apache 2.0。[faster-whisper 官方文件](https://github.com/SYSTRAN/faster-whisper)、[模型來源](https://huggingface.co/Systran/faster-whisper-small)、[OpenCC](https://github.com/BYVoid/OpenCC)。
