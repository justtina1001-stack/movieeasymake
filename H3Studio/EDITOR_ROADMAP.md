# 剪輯室功能範圍與後續順序

此工具以本機生成作品接續剪輯為主；以下明確區分目前功能與尚未實作項目，不代表已完整替代 CapCut。

| 類別 | 本輪可用範圍 | 尚未實作 |
| --- | --- | --- |
| 基本剪輯 | 影片左右邊界拖曳裁切／恢復來源內容、分割、排序、複製／刪除、復原／重做、自動儲存／草稿恢復、專案另存／開啟、含素材的完整專案備份／讀回、影片圖層疊加／畫中畫；按住片段上下拖曳換層、同軌多片段／相鄰排列／空白定位、主軌與上層互移、落點插入線／取消／吸附 | 可切換的跨軌波紋／滑移剪輯、跨專案素材管理 |
| 音訊 | 四音軌、左右邊界拖曳、同軌邊界限制、原聲分離、獨立定位／音量、淡入淡出、混音匯出 | 錄音、音訊波形、降噪、人聲隔離、響度正常化、音訊效果 |
| 速度 | 0.25～4 倍固定／曲線變速、七種曲線預設、拖曳與精確輸入控制點、曲線展開編輯、原聲保留音高、依速度調整片段長度、同軌後續片段順移並保留間距；主影片與影片圖層可用，分離原聲保留曲線 | 光流補幀、倒放、定格 |
| 預覽效能 | 下一段預載與提前定位、重用素材、選用流暢預覽快取、最多 3 個活躍上層影片合成 | GPU 效果管線 |
| 輸出 | 橫／直／方形（含 1080p）、MP4 H.264/AAC、24／25／30／60 fps、進度與取消 | 自訂編碼、4K、透明影片、獨立音訊匯出 |
| 字幕與文字 | 多行中文文字圖層、顯示時間、字級／顏色／粗體／底色／對齊、描邊粗細與顏色、雙色線性漸層與角度、位置／縮放／旋轉／透明度、圖層順序、淡入淡出、位置關鍵幀與緩動、預覽與 MP4 匯出 | SRT 匯入／匯出、自動辨識字幕、逐字及套版文字動畫、多色／徑向漸層 |
| 畫面處理 | 保持影片比例與黑邊；PNG／JPEG／靜態 WebP 圖片疊加、透明 PNG、圖片／影片圖層的位置、大小、旋轉、透明度及顯示時間；影片／文字／圖片淡入淡出；文字／圖片位置關鍵幀 | 主影片裁切／位置／旋轉、影片及其他參數的關鍵幀、調色、轉場套件、遮罩 |

建議接續順序：

1. **字幕與主影片基本調整**：SRT 匯入／匯出、主影片裁切／縮放／旋轉，預覽與匯出一致。
2. **轉場與時間軸**：在現有影片疊層、畫中畫與淡入淡出上，加入常用轉場與更完整的時間軸吸附。
3. **進階音訊及速度**：波形、錄音、響度／降噪、光流慢動作；需另外測試 CPU／GPU 成本及音畫同步。
4. **關鍵幀與效果**：在文字／圖片位置動畫上，增加影片、縮放／旋轉／透明度動畫、調色與遮罩等，保持復原、預覽與匯出一致。

自動字幕、去背、追蹤、光流等 AI 功能需選擇對應開源模型／運算方式及確認授權；現有 H3 生成模型不等於具備這些剪輯能力。本輪未加入新的 AI 模型或外部付費服務。

比對依據為 2026-09-29 查閱的 CapCut 官方[音訊混音](https://www.capcut.com/tools/audio-mixing)、[音訊編輯](https://www.capcut.com/tools/online-audio-editor)、[固定變速](https://www.capcut.com/tools/change-video-speed)、[曲線變速](https://www.capcut.com/tools/speed-ramp)與[桌面編輯功能](https://www.capcut.com/tools/desktop-video-editor)說明。各平台及方案能力可能不同，不以官網功能介紹作為本工具已實作或效能相同的證據。
