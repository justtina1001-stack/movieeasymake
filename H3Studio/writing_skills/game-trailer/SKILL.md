# Game / Character Trailer — H3 Studio adaptation

## Writing rules
Establish the character's readable silhouette, costume, held prop and environmental scale using the provided references. Choose one signature action with anticipation, weight transfer, main motion, reaction and settled pose. Keep weapon and hand identity consistent. Limit effects so the character, action path and result remain visible; give each effect a source and timing. Use a motivated reveal or tracking move rather than repeated unrelated angles. Finish with a stable, identifiable hero pose or visible action result. Do not invent unsupplied gameplay, UI, logos or release information.
