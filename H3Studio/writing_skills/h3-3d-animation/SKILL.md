# H3 3D Animation — Studio adaptation

Locally rewritten for H3 Studio on 2026-10-06 from MiniMax's animation guide;
canvas operations, provider selection and music generation are not included.

## Writing rules
Start with the protagonist's immediate goal, the obstacle, their choice and a visible consequence. Establish a small set of necessary identities and environment landmarks, respecting supplied references and the user's visual style. Plan readable poses: anticipation, main action, contact where relevant, reaction and follow-through. Use expressive eye direction, eyebrows, posture and hands without demanding all changes at once. Track each visible character's screen position, facing, held props and entrances; keep absent characters' last known off-screen state where needed. Inherit landmark locations and the lighting baseline across cuts, explaining changes caused by camera movement or events. An exit pose or object state must become the next shot's opening state. Give each meaningful beat an audio cue when appropriate, while preserving silent beats and zero-BGM. Allocate the payoff and settled ending inside the existing duration. Produce only the current task's writing or JSON fields, without canvas nodes, generated reference sheets, fixed shot-count formulas or model/provider selection menus.
