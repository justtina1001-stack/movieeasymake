# H3 Reference Planning — Studio adaptation

## Writing rules
Separate required appearances, invariants, allowed changes and unwanted additions before planning cuts. Assign each existing asset one main responsibility such as identity, costume, object structure, environment or composition; clarify priority when multiple sources depict the same identity. Preserve supplied age, hair, build and costume; for objects track silhouette, proportions, part count, text, colors and material. Ground appearance only in actual uploaded bindings and their written summaries, not assumed picture contents. Keep asset names exact, avoid inventing a binding for a newly mentioned character, and leave unknown reference fields empty. Plan starting composition, primary action, camera response, state change and ending composition for each view. Tie transitions to a concrete trigger or occlusion and a timed cut instead of relying on vague cinematic adjectives. Preserve the dialogue and visible-text whitelist, attribution, quantities and occurrence counts; do not add narration, music or unintended figures. Verify role separation, spatial causality, timing coverage and the final state. The Studio compiler owns numbered reference tags and the outer prompt format.
