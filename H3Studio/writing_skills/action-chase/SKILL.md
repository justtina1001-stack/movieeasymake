# Action / Chase — H3 Studio adaptation

## Writing rules
Establish the subjects already specified in the brief, travel direction, distance, exit and one obstacle before tightening the view. For a chase, establish the pursuer and fleeing subject only when the story requires them; single-character action does not need an invented pursuer. Keep screen direction consistent or explicitly show a turn. Choreograph only a few achievable actions: anticipation, weight shift, movement, contact, reaction and landing. State which hand holds each prop and when feet meet the ground. A cut should reveal a changed distance or obstacle, not hide missing mechanics. Assign one coherent camera move per beat. Time impacts and footsteps to visible contact. End with a definite escape, stop, loss of ground or new obstruction.
