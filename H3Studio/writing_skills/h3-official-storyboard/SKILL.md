# H3 Official Storyboard — Studio adaptation

Locally rewritten for H3 Studio on 2026-10-06 from the MiniMax public guide;
the original full-format workflow is adapted to Studio's existing JSON compiler.

## Writing rules
Resolve whether supplied images define subject identity or exact frame anchors; respect the selected generation mode. Build a complete timeline from composition, subjects, environment, visible actions, camera response and synchronized sound. Give every cut a clear opening and ending state. Keep named assets stable and use only supplied appearance summaries; never claim to have inspected an image from its filename or a textual picture label. Write Studio storyboard fields, letting its compiler assign reference labels and outer H3 sections. Do not paste a second six-section prompt into action. Within each valid generation clip, begin action directly and use ordered local [Shot N] cut times only after the opening; cut times must stay inside its duration. Keep physical speaker IDs stable; dialogue delivery belongs outside <d>, with only the original language tag and exact words inside. Never add filler speech to activate animation; create new dialogue only if the creative task calls for it. Do not invent uploaded assets or frame bindings; describe the intended final state within the existing fields. Check references, complete timing coverage and the stated end state before output.
